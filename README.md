# Veer Vigyan - Free Science Education Platform

**Veer Vigyan** is a comprehensive, responsive educational website designed to provide free science education resources for students in classes 9-12. Built entirely with HTML, CSS, and JavaScript, it offers a rich learning experience with notes, test series, books, and MCQs.

## 🎯 Features

- **Responsive Design**: Works seamlessly on mobile, tablet, and desktop devices
- **Animated Gradient Background**: Smooth color transitions between light green and soft blue
- **Card-Based Layout**: Modern, clean interface with interactive cards
- **Liquid Button Effects**: Fluid animations on hover with wave/bubble effect
- **Interactive Sections**:
  - Educational notes with filtering options
  - Grade and subject-specific test series
  - Recommended book listings
  - Comprehensive MCQ collections
- **Sticky Navigation**: Smooth scrolling navigation with active state tracking
- **Accessibility**: WCAG compliant with proper ARIA attributes
- **Performance Optimized**: Efficient animations and minimal reflows

## 🛠️ Technologies Used

- **HTML5**: Semantic markup with proper ARIA labels
- **CSS3**: Flexbox, Grid, animations, and transitions
- **JavaScript ES6+**: Modular functions and interactive features
- **Google Fonts**: Cinzel Decorative for headings, Cormorant Garamond for body
- **Font Awesome**: Icons for enhanced UI elements

## 🚀 Getting Started

1. Clone or download the project files
2. Open `index.html` in any modern web browser
3. Explore the various sections and interactive elements
4. Customize content as needed for your educational platform

## 🎨 Design Highlights

- **Color Palette**: Light green (#E0F7FA to #C8E6C9) and soft blue (#E3F2FD to #BBDEFB)
- **Typography**: Cinzel Decorative for headings, Cormorant Garamond for body text
- **Layout**: Card-based design with subtle shadows and rounded corners
- **Animations**: Smooth transitions and hover effects throughout

## 📱 Responsive Behavior

- **Desktop**: Full-width layout with multi-column grids
- **Tablet**: Adjusted spacing and optimized for medium screens
- **Mobile**: Collapsible navigation menu and single-column layout

## 🔧 Customization

To customize the content:

1. Modify the sample data arrays in `script.js` (notesData, testData, booksData, mcqsData)
2. Update the styling variables in `:root` in `styles.css`
3. Add or remove sections as needed in `index.html`
